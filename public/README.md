# Memory photographs

Replace `memory-1.jpg` through `memory-5.jpg` with your own photographs, or add new files here and update `src/config/birthdayConfig.ts`.

For the best results, use JPG or WebP images at least 1200px wide. Landscape and portrait images are both supported; the site crops them to the cinematic photo frame.
